# Разборы английской грамматики

Самодостаточные одностраничники по темам английской грамматики.
Каждая страница — один HTML-файл без сборки и зависимостей: открывается двойным кликом,
работает офлайн (кроме подгрузки шрифта Montserrat).

**Живая версия:** https://timaxmetov.github.io/english-grammar/

## Страницы

| Тема | Файл |
|---|---|
| Present Perfect Continuous | [index.html](index.html) |

## Что внутри страницы

- прогресс-бар чтения и боковая навигация по секциям;
- многоступенчатая диаграмма формулы (mobile-first: на телефоне вертикальная лестница, на десктопе — горизонтальная лента);
- анимированный видеоразбор на SVG с таймлайном, субтитрами и главами — без внешних видеохостингов;
- **озвучка английских примеров** через Web Speech API: динамик у каждой фразы, выбор голоса и темпа;
- интерактивный тренажёр: сборка предложения, заполнение пропуска, выбор времени; счёт, серия и разбор каждой ошибки;
- выгрузка шпаргалки в `.txt`.

## Технические заметки

- Mobile-first: базовые стили описывают телефон, дальше точки 560 / 768 / 1200px.
- Кегль гигантских заголовков привязан к ширине самой длинной строки, чтобы она не обрезалась.
- Видеосцена имеет две раскладки: на узком экране `viewBox` сжимается и кубики формулы встают в столбик.
- Озвучка работает на голосах операционной системы. Если английских голосов нет, панель честно об этом сообщает.
- Учтён `prefers-reduced-motion`.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для проверки в условиях, близких к продакшену, есть сервер без зависимостей:

```bash
node serve.js
```

Откроется на `http://localhost:8080/`. Другой порт — `node serve.js 8081`.
